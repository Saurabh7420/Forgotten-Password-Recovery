# Locked Files

Place **exactly one** password-protected file in this directory.

## Supported Formats

| Format | Extension(s) |
|---|---|
| ZIP Archive | `.zip` |
| PDF Document | `.pdf` |
| Word Document | `.docx` · `.doc` |
| Excel Spreadsheet | `.xlsx` · `.xls` |
| PowerPoint | `.pptx` · `.ppt` |
| 7-Zip Archive | `.7z` |

## Multiple Files

If you place **more than one** supported file in this folder, the tool will  
show you an **interactive numbered picker** to select which one to process.

## Notes

- Only **regular files** are scanned — subdirectories are ignored.
- Files with unsupported extensions are listed in a warning but do not block the tool.
- Files in this directory are excluded from Git via `.gitignore`.

## Privacy

Your locked file stays on your machine. It is **never** uploaded or transmitted anywhere.
